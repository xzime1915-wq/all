# Inventory Management System

A clean, modern inventory‑management web app for **your tech company**.

- **Backend**: Node + Express, TypeScript, Prisma (SQLite for development, easy to switch to PostgreSQL).
- **Frontend**: React + Vite, TypeScript, Material‑UI, responsive design.
- **Features**:
  - Product CRUD
  - Stock‑level tracking & low‑stock alerts
  - Barcode/QR scanning (via `react-qr-reader`)
  - Role‑based access (admin/manager/viewer)
  - Simple reports & CSV export

Place your company logo (e.g., `tech(4).png`) into `frontend/src/assets/` and it will appear in the app header.
